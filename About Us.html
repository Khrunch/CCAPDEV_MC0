About TerryPick

TerryPick is a simple booking and discovery prototype for pickleball courts. The goal is to help players find nearby courts quickly, save favorites, and plan sessions with less effort.

What you can do

Discover courts

Browse sample listings and see basic details like indoor/outdoor, number of courts, and availability.

Save favorites

Bookmark courts you like so you can come back to them faster.

Manage bookings

View upcoming sessions from your Profile page (sample data for now).

Why we built it

This site was created as a course project to demonstrate basic UI pages, navigation, and simple “logged in” behavior. It currently uses front-end demo authentication (localStorage) and sample content.
